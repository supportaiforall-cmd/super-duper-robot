## Build

**Required:** [Adventure Game Studio 3.6.2 Patch 12](https://www.adventuregamestudio.co.uk/releases/finals/AGS-3.6.2P12/AGS-3.6.2.22-P12.exe) on Windows.

Replace the example paths below with the AGS Editor installation path and the tracked Game.agf path once the project is added.

**Command Prompt:**

```bat
"C:\path\to\AGSEditor.exe" /compile "C:\path\to\Game.agf"
```

**PowerShell:**

```powershell
& "C:\path\to\AGSEditor.exe" /compile "C:\path\to\Game.agf"
```

If AGSEditor.exe is on PATH, you can use its name instead of the full executable path. A successful compile exits with code 0; compile errors return a non-zero code. See the [AGS Editor command-line options](https://adventuregamestudio.github.io/ags-manual/v3/EditorCommandLineOptions.html).
