## Build

**Required:** [Adventure Game Studio 3.6.2 Patch 12](https://www.adventuregamestudio.co.uk/releases/finals/AGS-3.6.2P12/AGS-3.6.2.22-P12.exe) on Windows.

In Command Prompt or PowerShell, compile the project:

```powershell
AGSEditor.exe /compile "C:\path\to\Game.agf"
```

Replace the example path with the tracked Game.agf path once the AGS project is added. If AGSEditor.exe is not on PATH, use its full installation path. A successful compile exits with code 0; compile errors return a non-zero code. See the [AGS Editor command-line options](https://adventuregamestudio.github.io/ags-manual/v3/EditorCommandLineOptions.html).
